# Newsroom

This directory contains public, English-language announcements for Codex Text Control.

Its input is a frozen release scope, verified project evidence, and the matching changelog entry. Its output is a public announcement that explains the user problem, the shipped change, the available evidence, and the remaining limits. Each announcement depends on the linked source and evidence records; it does not replace technical documentation, independent verification, or a real-host acceptance test.
