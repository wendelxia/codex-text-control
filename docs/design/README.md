# 设计文档索引

## 用途、输入和输出

本目录保存已经冻结的系统边界和设计决定。输入是用户需求、真实失败、代码结构与验证结果；输出是实现前后的设计约束、数据流和取舍记录。

阅读这些文档只需要理解 Markdown 和项目目录结构；维护实现时还需要 Node.js 22 或更高版本。限制是带版本号的设计文件反映当时决策，不会在后续版本中改写历史；判断当前实现时应优先读架构说明和最新验证记录。

## 客观评价

当前文档能解释核心存储、画布和确认边界，也保留了被真实测试否定的早期方案。它还不是正式的接口参考手册；工具输入结构以 MCP 服务器代码和测试契约为准。
