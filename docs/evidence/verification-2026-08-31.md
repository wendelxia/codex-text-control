# 0.2.0 验证记录（2026-08-31）

## 用途

本文件保存候选版本的原始检查口径。输入是源码和锁定依赖，输出是测试、协议探测、安全审计与真实宿主状态。它不是第三方认证，也不能替代用户验收。

## 固定环境

- 操作系统：Windows，PowerShell。
- Node.js：本机 `v24.16.0`，并用 Node 22 兼容运行时复核测试与 MCP 探测。
- Python：`3.11.2`，只用于插件清单校验，不参与运行时。
- npm 依赖：由 `package-lock.json` 锁定。
- 安全数据源：`https://registry.npmjs.org/` 官方漏洞和签名接口。

## 已证实

| 检查 | 命令或方法 | 结果 | 能证明什么 |
|---|---|---|---|
| 自动行为测试 | `npm test` | 19/19 通过 | 已覆盖的存储、权限、桥接、超时和界面状态符合断言。 |
| 语法检查 | `npm run check` | 通过 | 指定 JavaScript 文件能被 Node 解析。 |
| MCP 集成探测 | `npm run probe:mcp` | 通过 | 独立 MCP 客户端能列工具、打开资源、保存、提交并读回指针。 |
| 干净副本复现 | 不复制 `node_modules`，执行 `npm ci --ignore-scripts && npm run quality` | 通过 | 结果不依赖原目录旧依赖残留，也不需要第三方安装脚本。 |
| Node 版本兼容 | Node 22 和 Node 24 分别运行测试及 MCP 探测 | 两档均通过 | 当前声明的最低 Node 主版本与本机新版均能执行核心检查。 |
| npm 漏洞审计 | `npm run audit:prod` | 0 个已知漏洞 | 官方数据库当前未报告生产依赖漏洞。 |
| 签名与来源 | `npm run audit:signatures` | 96 个包签名、11 个来源证明通过 | 下载包的 npm 签名和来源信息能被当前工具验证。 |
| 响应式布局 | 320、375、768、1024、1280、1440 像素浏览器检查 | 无横向溢出 | 指定视口下布局没有水平滚动。 |

## 未证实

- 尚未由用户在当前 Codex 宿主里连续两次完成保存和提交。
- 尚未验证 macOS、Linux 和其他 Codex 版本的真实 Widget。
- 尚未验证屏幕阅读器、完整键盘焦点顺序和高对比模式。
- 尚未经过独立安全审计或外部权威基准。

## 失败项

- 当前真实宿主临时验收目录仍为 0 个修订、0 个权威版本，说明用户点击证据尚未产生。
- 当前源码开始本轮前不是 Git 仓库，也没有 CI、根许可证和变更记录；本轮已补文件，但线上 CI 仍要在 GitHub 推送后才有证据。
- 插件清单曾声称“查看版本差异”，实际只有历史载入；本轮已修正文案，真正 diff 仍未实现。

## 限制和客观评价

当前证据等级是“验证通过的本地候选版”，不是“可用”或“可发布”。自动化质量比若干零到两星直接同类扎实，但真实用户闭环和公开发布链仍有缺口。
