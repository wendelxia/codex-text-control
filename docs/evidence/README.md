# 验证与调研证据索引

## 用途、输入和输出

本目录把测试记录、真实宿主结果和公开项目调研与设计文档分开保存。输入是可重复命令输出、用户真实点击结果、失败样例和只读公开资料；输出是按版本可追溯的证据记录。

复现自动化需要 Node.js 22 或更高版本和 npm；复现真实宿主结果还需要支持 MCP Apps（MCP 应用）的 Codex 桌面宿主。限制是历史记录只证明当时写明的机器、版本、样本和任务，不能自动外推到当前版本或其他环境。

## 建议阅读顺序

1. 先读 [`verification-0.5.9-2026-09-02.md`](verification-0.5.9-2026-09-02.md) 了解当前连续正文画布改动，再读 [`verification-0.5.8-2026-09-01.md`](verification-0.5.8-2026-09-01.md) 了解底层并发与原文保真证据，最后读 0.5.7 记录核对最后一次真实宿主结果。
2. 再读 [`real-host-multi-test-0.5.3-2026-09-01.md`](real-host-multi-test-0.5.3-2026-09-01.md) 了解真实失败如何推动取消实时保存和修复长文控制。
3. 需要比较项目定位或 README 结构时，分别读功能对比和首页对照记录。
