## 已证实、未证实与失败项

### 已证实

- 仓库自动化、MCP 探针、已知生产漏洞检查、供应链签名和安装文件一致性通过。
- 真实用户能完成正文、表格、源码、中文和快速输入，并把最终权威版本回传给 Codex。
- 纯文本渲染在本次真实输入中没有执行测试标签。
- 不存在的扩展点会拒绝且不写入。

### 失败项

- 长文滚动到底部时，用户需要的顶部控制内容不可见。
- 实时自动保存产生大量输入法中间修订，与用户“不需要实时保存”的最新要求冲突。

### 未证实与限制

- 没有验证第二台设备、不同缩放比例、不同输入法、离线恢复、宿主崩溃恢复和长时间连续使用。
- 没有独立复核，也没有适用于自然语言触发路由的外部权威基准；路由只能报告内部契约和真实样例。
- Computer Use（计算机操作）安全规则禁止自动操控 Codex 桌面应用，因此真实宿主交互由用户点击并在权威正文中记录，没有自动截图证据。
- 早先曾观察到完成编辑后的旧画布又产生一个截断修订，但本轮没有隔离复现，暂不能确定因果。

## 版本判定

`0.5.3` 的核心编辑闭环已有真实可用证据，但完整候选验收不通过，不能称为“可发布”或“生产可用”。阻断项是长文控制不可见，以及保存策略与用户确认需求冲突。下一版应先冻结新的保存契约：编辑期间只保留本地草稿，在“完成编辑”或用户明确保存时生成一个不可变修订；同时修复长文下的常驻控制可见性。修复后必须重跑本文同一协议，并保护已通过的正文、表格、源码、安全显示、扩展点拒绝和单次通知能力不退步。
