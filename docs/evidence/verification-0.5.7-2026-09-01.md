# 0.5.7 工作区绑定候选验证记录（2026-09-01）

## 用途、输入和输出

本文件记录 0.5.7 对“建议画布必须绑定当前工作区，不能把插件安装缓存当成项目”的修复与验证。输入是 0.5.6 重启后的真实 MCP 返回、当前技能规则和内部协议测试；输出是必填项目目录协议、技能约束、失败证据、回归结果和回退方法。

依赖 Codex 工作区信息、MCP Apps（MCP 应用）、Node.js 22 或更高版本和 npm。限制是本次真实结果只覆盖当前 Windows 机器、当前用户、当前 Codex 桌面宿主和一个项目工作区，不能外推到其他平台或宿主版本。

## 真实失败与根因

0.5.6 完全重启后，一份不长但可采用的建议成功自动打开画布，证明建议正向触发已生效。但第一次调用省略了 `projectDir`，真实返回显示：

- 错误项目目录：插件安装缓存 `0.5.6+codex.20260901104738`。
- 错误版本库：插件缓存下的 `.codex-text-control/`。
- 当前权威版本：无。

随后显式传入 `<当前工作区>`（公开文档已脱敏），真实返回恢复为该工作区的权威版本 `rev-1788224700158-cef4c579`，版本数量为 40。根因是 MCP 的 `projectDir` 原为可选，省略后使用 `process.cwd()`；插件进程的工作目录就是安装缓存。

第一次错误调用只创建了一个空版本目录，文件数为 0；确认目标绝对路径位于 0.5.6 安装缓存且不含文件后已删除，没有修改当前工作区的 40 个版本。

## 修复边界与数据流

- 所有 MCP 工具的 `projectDir` 改为必填非空字符串，缺少时在协议校验层直接拒绝。
- Widget 打开后继续把已经验证的项目目录传给保存、提交和恢复操作。
- 技能要求读取权威上下文、打开画布和编辑扩展点时，每次都显式传入当前工作区根目录。
- 不改 Markdown、修订文件、权威指针、画布界面和已有数据。
- 若当前工作区不可确定，工具明确失败；不得猜测或退回插件安装目录。

## 测试驱动证据

新增两个契约并在 0.5.6 上稳定失败：MCP 仍接受缺少项目目录的画布调用；技能没有要求每次调用绑定工作区。修改后：

- 两项聚焦契约均通过。
- 显式传项目目录的渲染编号回归通过。
- 完整自动测试 `57/57` 通过。
- JavaScript 语法检查、MCP 闭环探针和官方技能结构校验通过。
- 生产依赖已知漏洞 `0`；包签名 `96`；来源证明 `11`。
- 同一候选连续完整测试 10 次，共 `570` 项断言，失败运行 `0`，观察到的不稳定率为 `0/10`。

## 已证实、未证实、失败与限制

### 已证实

- 真实宿主中建议正向触发已经发生。
- 省略项目目录会串到插件缓存的问题有真实返回和稳定自动测试共同复现。
- 0.5.7 源码层会拒绝缺目录调用，显式目录的既有编辑闭环继续通过。
- 误建的空缓存目录已安全清理，当前工作区已有权威版本未被改动。

### 完全重启后的真实宿主复验

- 完全重启 Codex 后加载的构建为 `0.5.7+codex.20260901154437`。
- 当前画布绑定到用户打开的工作区；所有 MCP 调用显式传入该工作区根目录，没有再回退到插件安装缓存。
- 用户修改了完整验收原文，点击“完成编辑”后先看到逐字完整的待提交内容。
- 第一次点击“返回修改”时没有产生版本通知，刚才的草稿仍保留。
- 再次点击“完成编辑”并点击“确认提交”后，只回传一个新版本号；最终权威版本为 `rev-1788249723947-c7d6a499`。
- Codex 随后通过 `get_authoritative_context` 回读到标题、六步操作、Markdown 表格和“验收状态：已修改”，证明版本通知和磁盘权威内容一致。

### 未证实

- 没有第二台设备、第二位用户、其他操作系统或其他 Codex 版本的真实宿主结果。
- 没有公开远程仓库、线上持续集成、公开发行版和陌生用户从零安装记录。
- 当前缺少适用于 Codex 工作区路由和上下文画布的外部权威基准，不能声称领先同类项目。

### 失败与限制

- 0.5.6 的首次真实建议画布绑定错误项目，已判为阻断失败，不能晋升。
- 当前工作区根目录依赖 Codex 在会话环境中提供；信息缺失时新版本选择明确失败，用户需要重新打开正确项目。

## 回退与真实验收

当前真实宿主复验已经通过，不需要回退。后续若发现工作区绑定、完整原文检查或单次提交回归，可重新安装 0.5.6 仅用于对照诊断，但不得省略项目目录，也不建议继续编辑。数据格式没有变化，不需要迁移。

客观结论：`0.5.7` 已在当前 Windows Codex 宿主完成核心点击闭环，可以称为“当前环境可用的本地候选版”；由于跨平台、公开安装、线上持续集成和外部基准仍缺失，不能称为公开可发布或生产可用。
