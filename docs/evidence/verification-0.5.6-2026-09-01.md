# 0.5.6 建议触发候选验证记录（2026-09-01）

## 用途、输入和输出

本文件记录 Codex Text Control 0.5.6 对“提建议时也需要进入上下文画布”的实现与验证。输入是用户的真实触发要求、0.5.5 技能规则和内部路由契约；输出是更明确的技能描述、回归测试、候选门槛结果和安装核对。

依赖 Codex 技能路由、Node.js 22 或更高版本、npm 和现有 MCP Apps（MCP 应用）插件。限制是自动化只能验证技能规则是否完整，不能代替完全重启后的真实 Codex 模型路由。

## 边界与判定

- 最终回复的主要内容是在提出用户可继续采用或修改的建议时，自动打开画布。
- 建议不要求很长、有表格、连续编号或已经成体系。
- 随手附带的一句提醒、简短对话、普通解释、进度、日志和代码或文件交付仍不触发。
- 不改变画布界面、MCP 工具、保存流程、修订格式和权威指针。
- 路由错误时不会写盘；画布初次打开和编辑过程仍不保存，只有用户点击“完成编辑”才更新权威版本。

## 已证实、未证实、失败与限制

### 已证实

- 技能的加载前描述和加载后正文都明确包含可采用建议的自动触发条件。
- 既有简短对话、文件交付、编辑保存、表格、扩展点和版本通知契约没有因本次文字规则修改而退步。
- 没有新增依赖、网络权限、存储格式或数据迁移。

### 未证实

- 尚未在完全重启后的 Codex 中真实验证一条不长但可采用的建议会打开画布。
- 尚未真实验证随手附带的一句提醒仍保持普通回复。
- 当前缺少适用于 Codex 技能路由的外部权威基准，不能声称路由能力领先同类项目。

### 失败与限制

- 0.5.5 的“成体系”限定未满足本次要求，已由新增契约稳定复现并修正。
- 技能规则不能保证模型在所有表达方式下百分之百路由正确，真实正反例仍是晋升门槛。
- 完全重启后的真实建议正例成功触发 Widget，但首次调用未传 `projectDir`，MCP 把插件安装缓存误当成项目目录。0.5.6 因此未晋升，后续修复转入 0.5.7。

## 回退与真实验收

如建议触发过多或漏触发，重新安装 `0.5.5+codex.20260901100013`。MCP 工具、修订文件和权威指针格式没有变化，不需要迁移数据。

完全重启 Codex 后至少验证两个真实例子：一份不长但可继续采用或修改的建议应打开画布；一条随手提醒或文件交付说明不应打开画布。两项都通过前，0.5.6 只能称为本地候选版。
