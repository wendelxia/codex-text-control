# 0.5.2 直接正文编辑候选验证记录（2026-09-01）

## 用途

本文件记录 0.5.2 删除结构增项后的验证证据。输入是用户明确反馈“能正文编辑的，就不需要增加别的增项了”；输出是只保留直接文字、表格单元格、源码编辑和版本闭环的画布。依赖 Node.js 22、Codex MCP Apps（MCP 应用）桥接和 Chromium；当前没有适用的外部权威基准，属于内部工程验证。

## 边界与数据流

用户直接修改文字块、表格单元格或 Markdown 源码，前端序列化为完整 Markdown，停顿后由 `update_authoritative_context` 保存不可变修订并更新权威指针，点击“完成编辑”后只回传一次版本通知。界面不再提供新增段落、新增表格、删除当前块或表格行列工具；结构变化统一在源码视图完成。

保存超时会保留本地输入并显示结果未知；并发基准过期会拒绝覆盖；历史版本可以载入并另存为新修订。回退到 0.5.1 不需要迁移上下文数据。

## 已证实

- 测试驱动红灯：新增两项界面契约后稳定 2/2 失败，分别识别顶部结构按钮和表格行列按钮仍存在。
- 删除结构增项的底层未使用函数后，完整质量链 46/46 通过，包含测试、JavaScript 语法检查和 MCP 探测；表格解析、单元格修改、静默自动保存、完成通知、历史、扩展点和并发保护通过。
- 生产依赖审计发现 0 个已知漏洞；96 个包签名和 11 个来源证明通过。
- 1280x720 Chromium 中，直接文字和表格单元格修改后自动保存，自动保存期间对话消息数为 0，点击“完成编辑”后精确变为 1；结构增项控件数为 0，按钮裁切、重叠和横向溢出均为 0。
- 桌面滚动到 `scrollY = 2092` 后控制条 `top = 0`；320x720 下滚动到 `scrollY = 2152.67` 后控制条 `top = 0`，按钮裁切、重叠和横向溢出仍为 0；控制台错误为 0。
- 最终候选安装号为 `0.5.2+codex.20260901010523`；安装副本哈希与质量链结果见本轮最终安装核验。

## 未证实

- 0.5.2 尚未在完全重启后的真实 Codex 中复验。
- 尚未由第二台设备、另一位用户或线上持续集成独立复现。
- 当前缺少外部权威验证，不能据此声称领先同类项目。

## 已知限制

- 直接删除整段、插入新段或改变表格行列需要在源码视图修改 Markdown；这是用户确认的范围收缩，不是隐藏能力。
- 可视画布仍会规范化部分 Markdown 表格分隔行空格，尚未达到未编辑内容逐字保真。
- 没有跨 MCP 进程原子文件锁，仍是发布前技术债务。

## 客观评价

0.5.2 用更少的界面概念覆盖真实需求，减少误操作和维护面；代价是结构变化需要理解少量 Markdown。自动化和普通浏览器证据已通过，但真实 Codex 新版闭环尚未完成，因此当前证据等级仍是候选版，不能标记为可用或可发布。
