# 0.2.2 触发规则候选验证记录（2026-08-31）

## 用途

本文件记录“我来改下”等省略宾语表达的触发规则修复。输入是用户真实失败样例、技能文件和安装候选；输出是回归测试、技能格式校验、安装一致性和真实宿主待验收项。它不是外部认证，也不能用自动测试代替 Codex 宿主中的自然语言触发。

## 目标和边界

- 目标：当前文存在正在讨论的回复、文字、规则或上下文时，“我来改下”“我自己改一下”“让我改”“我改改”应打开上下文编辑器，让用户亲自修改。
- 不触发：“我来改代码”“我改天再说”“我已经改完文件了”等明确不是修改当前上下文的表达。
- 不改变：存储格式、Widget（小组件）桥接、保存权限、提交权限和 `0.2.1` 用户数据。

## 未证实

- 尚未完全重启 Codex，让新技能元数据进入新的宿主会话。
- 尚未在真实对话中只输入“我来改下”，确认编辑器自动打开并装载紧邻的可编辑回复。
- 尚未在同一宿主中验证“我来改代码”“我改天再说”不会误开编辑器。

## 失败项

- `skill-creator`（技能创建器）提供的 `generate_openai_yaml.py` 第一次按 Windows 默认 GBK 编码读取 UTF-8 中文技能文件，报 `UnicodeDecodeError`。设置 `PYTHONUTF8=1` 后同一脚本成功；这说明生成脚本在中文 Windows 上不能依赖默认编码。
- 用户真实输入“我来改下”此前没有触发编辑器。原因是旧技能只列出带明确宾语的“修改刚才的文字”等例子，且触发描述没有覆盖用户要亲自修改但省略宾语的表达。

## 回退

重新安装 `0.2.1+codex.20260831101208` 可以回退触发规则。两个版本共用相同的修订和权威指针格式，不需要迁移或删除用户项目中的 `.codex-text-control/`。

## 限制和客观评价

当前证据等级是“自动验证通过且已安装的候选版”，还不是“真实宿主触发通过”。这次修复直接覆盖用户原话，并保留明确反例，方向正确；但自然语言技能路由由 Codex 宿主执行，只有完全重启后的真实输入才能证明最终行为。
