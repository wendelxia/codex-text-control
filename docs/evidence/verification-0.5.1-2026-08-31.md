# 0.5.1 连续编辑体验候选验证记录（2026-08-31）

## 用途

本文件记录 0.5.0 真实宿主验收暴露的两个阻断体验问题及 0.5.1 修复证据。输入是用户在真实 Codex 中的操作反馈、长 Markdown 和自动保存事件；输出是静默自动保存、一次完成通知和滚动时始终可达的顶部控制条。依赖 Codex MCP Apps 桥接、本地项目写权限、Node.js 22 或更高版本以及 Chromium；当前没有对应外部权威基准，属于内部工程验证。

## 冻结门槛

- 自动保存只更新不可变修订和权威指针，不发送用户消息，不把用户切回对话。
- 用户点“完成编辑”后只发送一次最新版本通知；未完成的保存必须先结束。
- “画布/源码”和编辑工具在长文滚动到底部时仍处于视口内。
- 320 像素宽度下按钮不裁切、不重叠，控制条不能完全遮住正文。
- 旧的存储、并发保护、扩展点、历史、安全纯文本渲染和表格能力不退步。

## 已证实

- 最终候选缓存号为 `0.5.1+codex.20260831154223`；插件清单、MCP 服务和 Widget 资源版本统一为 0.5.1。
- 真实 Codex 0.5.0 中，用户明确复现“每次改完后会出来跳窗”和“每次要上滑到最顶才能点选择块”。
- 修复前聚焦测试稳定出现 3 项失败：缺少完成入口、自动保存立即发消息、完成按钮不能主动保存。
- 修复后完整质量链 47/47 通过，包含 JavaScript 语法检查和 MCP 探测。
- 1280x800 Chromium 中滚动到 `scrollY = 3032` 后，控制条 `top = 0` 且仍完全可见；自动保存后消息数为 0，点击“完成编辑”后为 1；控制台错误为 0。
- 320x720 Chromium 中滚动到 `scrollY = 5237` 后，控制条 `top = 0`、高度 139 像素、按钮裁切 0、按钮重叠 0、页面横向溢出 0。
- 预安装候选 `0.5.1+codex.20260831153438` 曾通过 43 个候选文件缺失 0、SHA-256 哈希差异 0 和安装副本质量链 47/47；补写证据后尝试覆盖同一缓存目录被 Windows 以“拒绝访问”阻止，因此按插件更新协议生成新缓存号，不把旧副本冒充最终副本。

## 未证实

- 0.5.1 尚未在完全重启后的真实 Codex 中复验。
- 尚未由第二台设备、另一位用户或线上 CI 独立复现。
- 当前缺少外部权威验证，不能据此声称领先同类项目。

## 已知限制

- 0.5.0 真实验收还发现未编辑的 Markdown 表格分隔行会被统一空格格式；语义不变但不满足逐字保真，仍阻止“完整验收通过”。
- 自动保存期间若立即点“完成编辑”，界面会等待当前保存完成；超时或通知失败时保留本地内容和待发送版本。
- 没有跨 MCP 进程原子文件锁，仍是发布前技术债务。

## 客观评价

0.5.1 已用失败测试和普通浏览器运行时证据解决用户指出的两项交互阻断，但真实宿主仍只验证过旧版失败，尚未验证新版成功。当前证据等级仍是候选版，不能标记为可用或可发布。
