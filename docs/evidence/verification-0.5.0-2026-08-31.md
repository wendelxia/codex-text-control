# 0.5.0 上下文画布候选验证记录（2026-08-31）

## 用途

本文件记录“直接编辑上下文文字和 Markdown 表格”的候选验证。输入是权威 Markdown、用户画布操作和旧权威版本号；输出是新的不可变 Markdown 修订、权威指针和简短版本通知。依赖 Codex MCP Apps 桥接和本地项目写权限；当前没有对应外部权威基准，因此属于内部工程验证。

## 冻结门槛

- 普通文字和表格单元格可直接编辑，表格可增删行列。
- 常用 Markdown 往返稳定，复杂语法有源码恢复通道。
- 一次工具调用同时保存修订和更新权威指针，过期基准拒绝覆盖。
- 连续输入合并；保存期间的新输入不能被旧结果吞掉。
- 版本通知不包含全文；收到通知后模型读取最新版。
- 旧历史、扩展点块外不变、桥接超时、安全纯文本渲染和普通对话直通不退步。

## 未证实

## 已保留失败

- 首轮画布模型测试 4/4 失败，因为 `ui/canvas-model.js` 尚不存在。
- 首轮存储测试因缺少 `updateAuthoritativeContext` 导出失败；MCP 测试因缺少 `update_authoritative_context` 工具失败。
- 首轮 Widget 新能力测试 3/3 失败；实现画布后，旧两步按钮测试暴露为已废弃契约并按新风险重新编写。
- 自动保存初版会在旧请求返回过快时吞掉请求期间的新输入；回归测试稳定复现后加入编辑版本号保护。
- 移动端首张截图中工具按钮被压窄成逐字竖排；第二版改成横向滚动后隐藏了后部命令；最终改为按钮不收缩、工具栏自动换行，320 像素复验通过。

## 限制和客观评价

当前证据等级是“自动、普通浏览器和最终安装副本验证通过，真实 Codex 点击闭环待验收的候选版”，不能标记为可用或可发布。画布直接解决文字与表格难改的问题，简短通知也减少聊天重复；但常用 Markdown 以外的格式仍依赖源码视图，跨 MCP 进程文件锁仍是发布前技术债务。
