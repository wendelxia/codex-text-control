# Public Media

## Purpose

This directory contains GitHub-facing product media. Every visible word, subtitle, narration line, filename, and media description must follow the English-only rule in [`../design/public-media-language.md`](../design/public-media-language.md).

## Inputs And Outputs

The input is reviewed product source, frozen evidence, and an English storyboard. The output is a self-contained media package in [`codex-text-control-overview/`](codex-text-control-overview/) with a video, cover, subtitles, transcript, package guide, and machine-readable render report.

## Dependencies And Retention

The package is generated by `npm run render:promo:github`. Node.js, Chrome, FFmpeg, FFprobe, Windows speech synthesis, and an enabled English voice are required. Temporary frames and audio remain under the ignored `tmp/` directory; only the reviewed public package is retained in Git.

## Limits

Generated product screens use the current UI source with a simulated Codex bridge. They are not a real-host recording or evidence of product localization. The report makes the source, environment, public artifact hashes, and evidence limits inspectable, but output bytes can still differ across compatible browser, speech, font, and codec toolchains.

Objective assessment: this structure keeps promotional assets separate from product code and binds every published artifact to reproducibility evidence. It does not replace human review or independent user validation.
